# Team expected-points table

## What it exposes

For each possible fixed hand in seat 0 (mano), ep_mano exposes, by phase:

- Probability that Team A or Team B wins.
- Expected points for each team.
- Expected net points for Team A.
- Expected total points awarded.
- For Pares and Juego, additional probabilities describing whether both teams have a qualifying hand when a team wins.

The table is attached to each hand in probability_tables.pkl. It is generated by build_tables.py and compute_expected_points.py.

## How it is constructed

The worker treats the supplied hand as seat 0, fixes the configured alternating seat order, and enumerates compatible hand types for the other three seats. It precomputes Grande, Chica, Pares, Juego, and Punto ranks and hand properties, then weights outcomes by the physical multiplicities of sequential deals from the remaining deck.

It aggregates weighted points and win outcomes, then divides by total deal weight. It does not draw random samples. The optimized calculation is described in [Exact enumeration method](enumeration-method.md).

## Seat and phase assumptions

- Seats are ordered mano, opponent, partner, opponent.
- Equal phase ranks are resolved by the earlier seat. Seat 0 therefore wins a tie against an opponent when its hand is the Team A champion; a stronger partner hand can become Team A's champion, in which case the seat order against Team B still matters.
- Grande and Chica each award one base point to the team with the best individual hand.
- Pares and Juego award the intrinsic points from the winning team's qualifying hands.
- Punto is used only when no player has Juego and awards one point to the best Punto hand.

The current table fixes seat 0 as mano. It does not rotate the mano among seats.

## Expected wager adjustment

The agreed approximation adds a fixed +0.5 expected wager contribution in Pares when both teams have a qualifying pair, and in Juego when both teams have a qualifying Juego. This is an expectation, not a literal rule score or a simulation of a particular bid, fold, call, score situation, or player policy. The current scorer applies this convention.

Grande and Chica each award their base point to the best hand even when nobody wagers, so the model does not add a separate +0.5 there. Punto also receives no +0.5 under this approximation. This distinction is important: the Pares/Juego adjustment represents the expected wager contribution when both teams can contest that lance; it is not a universal bonus for every phase.

## What it is not

ep_mano is intended as a per-phase expected-points table for a fixed mano hand under the pre-mus deal model. Its values are deterministic sums over the current implementation's deal weighting; the opponent-pair symmetry audit remains open. It is not a complete value function for winning the 40-point game, and it does not include a learned opponent policy. The best-discard layer sums these expected net points as a practical hand-selection objective.
